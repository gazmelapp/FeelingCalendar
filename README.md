# 気分カレンダー（PWA）

毎日の気分を5段階の顔マークと一言メモで記録する、オフライン対応の個人用PWAです。

## 主な機能
- 月間カレンダーに気分マークを表示
- 日付ごとの気分・メモの保存、編集、削除
- `localStorage` に端末内保存
- Service Worker によるアプリファイルのキャッシュ
- iPhoneのホーム画面への追加に対応

## 公開方法（無料の例：GitHub Pages）
1. GitHubで新しいリポジトリを作成します。
2. このフォルダー内のファイルをすべてリポジトリ直下にアップロードします。
3. リポジトリの **Settings → Pages** を開き、公開元を `Deploy from a branch`、ブランチを `main`、フォルダーを `/(root)` にして保存します。
4. 公開された `https://...github.io/.../` のURLをiPhoneのSafariで開きます。
5. Safariの共有ボタンから「ホーム画面に追加」を選びます。
6. アプリを一度オンラインで開いて、ファイルのキャッシュが完了してからオフライン動作を確認します。
7. もう1台のiPhoneでも同じURLを開き、同様にホーム画面へ追加します。

## 保存とプライバシー
- 記録データは、アプリを使っているブラウザーの `localStorage` に保存します。
- サーバーへ気分やメモを送信する機能はありません。
- 2台のiPhone間で記録は共有されません。
- ブラウザーのサイトデータ削除、端末故障、ブラウザー環境の変更などでデータが失われる可能性があります。重要な記録には別途バックアップ機能の追加を推奨します。
- 同じURLでも、Safariと他ブラウザーでは保存領域が異なることがあります。ホーム画面から追加したアプリを継続して使用してください。

## 注意
PWAはHTTPSで配信する必要があります（`localhost` を除く）。ファイルをiPhoneへ直接保存して開くだけでは、インストールやオフラインキャッシュが正しく動かない場合があります。
