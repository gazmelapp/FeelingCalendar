# 気分カレンダー（PWA）

毎日の気分を5段階の顔アイコンと一言メモで記録する、オフライン対応の個人用PWAです。iPhone・Androidのブラウザーで利用でき、ホーム画面に追加してアプリのように起動できます。

## 主な機能
- 月間カレンダーに日ごとの気分を5段階の顔アイコンで表示
- 日付をタップすると「DAILY CHECK-IN」の入力ポップアップを表示
- 気分の選択、一言メモの入力、記録の保存・編集・削除
- 記録を保存すると入力ポップアップを自動で閉じる
- 一言メモがある日付には、カレンダーセル右下に小さなピンク色の点を表示
- 画面幅に合わせたスマートフォン向けレイアウト
- 記録はブラウザー内の `localStorage` に保存
- Service Worker によるアプリファイルのキャッシュとオフライン利用
- ピンク背景に5色の顔を並べたホーム画面用アイコン
- iPhone（Safari）およびAndroid（Chrome）のホーム画面追加に対応

## 表示・デザインの更新履歴
- 気分アイコンをオリジナル風の丸い顔イラストに変更。気分の色は良い方から「ピンク → オレンジ → 黄色 → 水色 → 紫」。
- 「記録を保存」ボタンを横長のピル型にし、中央に配置。スマートフォンでは入力欄の幅に合わせて表示。
- ホーム画面用アイコンを、ピンク背景に5色の顔を並べたデザインに変更。
- カレンダー下部の顔アイコン凡例を削除。
- アプリ最下部の説明文を削除。
- 最上部の「MY DAILY JOURNAL」を削除。
- 最下部の「ホーム画面への追加方法」リンクを削除。
- 「DAILY CHECK-IN」の入力欄は常時表示せず、カレンダーの日付をタップしたときだけポップアップ表示。
- メモがある日付の目印を顔アイコンの下中央ではなく、カレンダーセルの右下に表示。

## 公開方法（無料の例：GitHub Pages）
1. GitHubでリポジトリを作成します。
2. このフォルダー内のファイルをすべてリポジトリ直下にアップロードします。
3. リポジトリの **Settings → Pages** を開き、公開元を `Deploy from a branch`、ブランチを `main`、フォルダーを `/(root)` にして保存します。
4. 公開された `https://...github.io/.../` のURLをブラウザーで開きます。
5. iPhoneではSafariの共有メニューから「ホーム画面に追加」、AndroidではChromeのメニューから「ホーム画面に追加」または「アプリをインストール」を選びます（表示名は端末・ブラウザーのバージョンにより異なります）。
6. オンラインで一度開き、アプリファイルのキャッシュが完了してからオフライン動作を確認します。

## 更新方法
1. ZIPを展開し、ファイル一式を既存GitHubリポジトリの同じ場所にアップロードして上書きします。
2. `Commit changes` で変更を確定し、GitHub Pagesの公開処理が完了するまで待ちます。
3. ブラウザーでアプリを再読み込みします。ホーム画面アプリの更新には、オンラインで開いてから再起動・再読み込みが必要な場合があります。
4. 更新が反映されない場合は、URL末尾に一時的なクエリ（例：`?refresh=20261027`）を付けて開き、公開内容を確認します。Service Workerのキャッシュ名を更新した版では、新しいキャッシュへの切り替えを促します。
5. **ブラウザーのサイトデータやストレージを削除しないでください。** 記録データが消える可能性があります。

## 保存とプライバシー
- 記録データは、アプリを使っているブラウザーの `localStorage` に保存します。
- サーバーへ気分やメモを送信する機能はありません。
- iPhoneとAndroid、または異なるブラウザー間で記録は自動共有されません。
- ブラウザーのサイトデータ削除、端末故障、ブラウザー環境の変更などでデータが失われる可能性があります。
- 同じURLでもSafariと他ブラウザーでは保存領域が異なる場合があります。普段使うブラウザー／ホーム画面アプリを継続して使用してください。

## 技術・注意事項
- PWAはHTTPSで配信する必要があります（`localhost` を除く）。
- オフライン利用には、オンライン状態で一度アプリを開き、Service Workerによるキャッシュを完了させる必要があります。
- 記録の保存キーは `mood-calendar-records-v1` です。更新時に保存キーやデータ形式を変更すると、既存記録を引き継げなくなる場合があります。
